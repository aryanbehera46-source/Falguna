# Falguna v0.8 — project autonomy / safe discovery

## Frozen scope

Falguna may accept a selected approved project, one bounded natural-language engineering objective, and an optional cost cap. Before any worktree or modification it must inspect only tracked repository text, propose a narrow editable-file scope, and derive verification from repository metadata.

High-confidence discovery may continue into the existing isolated worker pipeline. Uncertain discovery, a dirty source repository, absent native verification metadata, or a material scope expansion must stop before editing and require human direction. The worker remains limited to the approved discovered files.

Reusable profiles cover ServiceFlow, Royal Table, Nivara Living, BriefPilot AI, and Falguna Engineering. Existing localhost, ModelGateway, worker abstraction, bounded repair, checkpoint/resume, DoD, evidence, audit, cost, semantic review, and pending protected-branch merge approval boundaries remain in force.

No Sales, Marketing, Finance, Trading, full TTT HQ, public hosting, marketplace, deployment, automatic merge, production secret, or unrelated Company OS work is included.
