# Falguna Bootstrap v0.4 — real-project engineering trial

Date: 2026-09-06 (Asia/Kolkata)

## Objective

Prove the v0.3 human-gated self-build loop on one genuine, bounded task in an established project repository. This stage does not authorize deployment, protected-main merge, hostile workloads, or expansion into Company OS functions.

## Selected task

ServiceFlow production base `615b645`: reject authenticated non-cancelled appointment reschedules outside the assigned provider's working hours or off the 30-minute scheduling grid, while preserving valid updates and the existing overlap check.

## Acceptance boundary

- Evidence that the defect existed before the trial.
- Requirement map before implementation.
- Isolated branch/worktree and exactly two worker-editable files.
- Replaceable structured worker and reviewer through the provider-independent transport.
- Native project suite under macOS Seatbelt with localhost-only networking.
- Playwright verification through the real login/admin UI and API.
- Runtime browser allowlist blocks a harmless external request.
- Independent four-dimension semantic review, complete hashed evidence, valid audit chain, and explicit cost records.
- At most one infrastructure-only H1; no human candidate-solution code.
- `DONE_CANDIDATE`, protected-main approval `PENDING`, and no merge or deployment.

## Out of scope

Sales, Marketing, Finance, Trading, TTT HQ, marketplaces, broader Company OS work, deployment, production data, automatic merge, secrets, paid infrastructure, and model upgrades.
